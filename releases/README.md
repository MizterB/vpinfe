# Earlier release notes

`RELEASE_NOTES.md` holds the release being cut. Before replacing it for the next one, copy
it here under the tag it shipped as, with an extension of `.md` (`v3.0.0-beta.1`, `v3.1.0`).

The What's new page shows a person every release they crossed since their last start, so
a person who skipped versions reads each one. A file here that is not named for a release
tag is ignored.
